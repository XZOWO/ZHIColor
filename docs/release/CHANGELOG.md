ColorOS 原生锁屏音乐主要停留在基础播放信息，歌曲播放时锁屏内容较为单一。ZHIColor 首个公开版本从这个场景出发，在保留系统播放链路的基础上，为锁屏音乐增加歌词、翻译、可调样式和音乐控制，让锁屏成为更完整的音乐信息界面。

- 接入 Lyricon 歌词数据，支持逐行、逐字歌词与翻译显示。
- 自定义歌词字体、排版、颜色、辉光、动效和刷新率。
- 按音乐应用设置翻译显示与翻译按钮。
- 清理歌词开头的版权提示、制作信息等内容，支持自定义清理格式和歌曲起始行。
- 隐藏锁屏与控制中心音乐卡片图标。
- 导入、导出和重置歌词配置，查看模块与歌词数据源状态。
- 在授权页完成 Root 与 LSPosed 授权，两项授权通过后进入应用。
- 在“关于”中检查更新，每次启动时自动检查一次，支持下载后通过 Root 更新安装及忽略单个版本的自动提醒。

使用应用需要 Root 与 LSPosed 授权；歌词功能还需要 Lyricon 与对应播放器的数据源。功能可用性取决于 ColorOS 版本和系统组件，兼容范围与安装说明见 README。
